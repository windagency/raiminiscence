4. Opportunistic consolidation: raw cost & contention (v14 / ADR-0021)

remember/recall schedule a full Clustering/Promotion/Promotion Audit/Commit Invalidation/Pruning/Invalidation pass via setImmediate on the same event loop as the MCP server — a cost the latency chart above never isolates, since the per-turn hook explicitly opts out of it. Contention is the actual user-facing symptom: how much slower the next recall() is right after a remember() that scheduled a pending pass (production's real default), vs. the same next call with nothing pending.
